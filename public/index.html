🤖 AI Card Studio — ระบบเพิ่มการ์ดใหม่เข้าสู่เกม

โครงสร้างเกมนี้ออกแบบให้ AI ตัวอื่นเพิ่มการ์ดได้ทันที 2 ช่องทาง:
  1. สำหรับ AI Coding Agent: ให้ AI อ่านไฟล์ AI_CARD_DEVELOPMENT_GUIDE.md ในโปรเจกต์ แล้วเพิ่มไฟล์การ์ดลงใน src/cards/decks/ หรือ src/cards/custom_cards.json
  2. วาง JSON การ์ดตรงนี้: ให้ ChatGPT / Claude / Gemini สร้าง JSON การ์ดตามเทมเพลตด้านล่าง แล้วกด "ตรวจสอบและบันทึกเข้าเกม" ได้ทันที!

รองรับทั้งโค้ด YDK และลิงก์ YDKE (ydke://...) จาก Master Duel Meta / EDOPro / YGOPro / Omega / YGOPRODeck: คัดลอก ydke://... หรือโค้ด #main ... #extra ... แล้วกดปุ่ม "📋 วางจาก Clipboard" หรือวางลงในช่องด้านล่าง (รองรับการ์ดทุกใบใน cards.cdb กว่า 13,000+ ใบ)

📖 คู่มือวิธีเล่น Yu-Gi-Oh! Master Duel (ฉบับเข้าใจง่ายใน 1 นาที)

1. สังเกตขอบการ์ดเรืองแสง ✨

การ์ดใบไหนบนมือ บนสนาม ในสุสาน หรือใน Extra Deck ที่สามารถทำแอคชั่นได้ จะมี ขอบสีทอง/ฟ้าเรืองแสง คลิกที่การ์ดเพื่อเลือกคำสั่งได้ทันที!

2. การอัญเชิญจาก Extra Deck 🌌

เมื่อบนสนามมีวัตถุดิบครบ (เช่น จูนเนอร์ + มอนสเตอร์รวมเลเวลเท่ากับมอนสเตอร์ซิงโคร หรือมอนสเตอร์เลเวลเท่ากัน 2 ตัวสำหรับ Xyz) ปุ่ม Extra Deck ซ้ายล่างจะเรืองแสง กดเพื่ออัญเชิญบอสได้เลย!

3. ระบบเชนเอฟเฟค (Chain Link) ⚡

เมื่ออีกฝ่ายใช้การ์ด และคุณมี Hand Trap (เช่น ฮารุ อุราระ / Ash Blossom) หรือการ์ดความเร็วสูง ระบบจะเด้งหน้าต่างถามว่าต้องการ เชนเอฟเฟคตอบโต้ หรือไม่ เหมือนใน Master Duel!

4. การเล่นกับเพื่อนผ่านมือถือ/คอมอีกเครื่อง 📱

หากใช้ Wi-Fi เดียวกัน ให้เพื่อนสแกน QR Code หรือพิมพ์ IP ที่แสดงในหน้าแรก หากอยู่คนละที่กัน (เช่น มือถือใช้ 4G/5G) ให้เลือกแท็บ "โหมดออนไลน์ข้ามเน็ต (P2P)" แล้วส่งรหัสห้อง 4 หลักให้เพื่อน!
